# AUX

The playbook incorporates the [ansible-role-aux](https://github.com/mother-of-all-self-hosting/ansible-role-aux) Ansible role. It helps you to manage auxiliary files and directories on your server.

It's useful for when you'd like to use Ansible to drop additional files on the server.

For details about configuring the role, you can check them via:

- 🌐 [the role's `defaults/main.yml`](https://github.com/mother-of-all-self-hosting/ansible-role-aux/blob/main/defaults/main.yml) online
- 📁 `roles/galaxy/aux/defaults/main.yml` locally, if you have [fetched the Ansible roles](../../docs/installing.md)
